## 优先修改的机制及验证边界

1. **让被蒸馏的量具备独立可检验的结构含义。** 当前教师关系只有分割损失间接约束，近均匀分布仍可工作。独立 sigmoid 局部边并以真实标签关系监督，比只改变温度或增大 KL 更直接地改变学习目标。二值标签提供的是同标注类别关系，背景不是一个物体，SOD 前景也不是通用 objectness；必须保留这些语义边界，且不能把 SOD/COD 当成互补分类。
2. **约束多模态收益经过可迁移的信息路径。** 当前教师所有尺度都接收 RGB/T/D 均值融合，关系聚合 value 也来自 T/D；学生只蒸馏注意分布。教师完全可能依靠融合特征变强，关系并未承担相应知识。考虑让真实 T/D 指导源结构，解码传播使用 RGB value，再验证关系置乱或关闭是否实质改变预测。当前没有该干预结果，不能宣称已证明旁路是唯一原因。
3. **保留一个稳定的源参考函数，而非只留下参数初始化。** 当前 Q/K/V/output 与源 decoder 协同训练；迁移时 decoder 丢弃，随后 encoder 解冻，关系分支的输入及其下游同时改变。若新方法要在 COD 阶段维持源知识，应明确冻结参考函数的完整输入到结构输出路径，同时用 COD GT 继续结构任务，让任务条件控制最终读出。是否减少遗忘必须测量，不能由“冻结”这一操作直接推定。
4. **把尺度与域任务差异纳入设计。** 当前只在 stride-16 的 3×3 网格传播，细边界和更长程结构是否不足没有直接证据；两个尺度可作为新框架设计，但需要新增可视化、边分类性能与干预量支持。源域真实 T/D 仅在 VDT 可用，COD 阶段始终 RGB-only，不应偷偷使用生成伪模态补齐输入。

下一版 `structure_v2` 应作为独立方法与新实验目录保留，relation_v1 及其负结果不覆盖。建议同时记录独立边预测质量、前景内部/背景内部/跨边界分层指标、关系干预的预测与指标差异、源参考与目标关系的变化，先证明中间知识真正参与决策，再评价多模态相对同结构 A/B/C 的净收益。当前未执行 structure_v2 GPU 训练，也没有它的效果数字；架构调整旨在针对观察到的问题，不能承诺必然实质提升。

### 修正前发现：16 位编码满量程使深度目标接近常数

初拟定义将 I;16 深度除以 65535，并使用 `exp(-abs(di-dj)/0.1)`。但这批实际深度多数图像的正值中位数约为 2022–2133，q99 约为 2152–2216；个别图像的范围更大。16 位存储类型并不代表图像使用了完整的 0–65535 动态范围，也不能据文件类型推断物理单位。固定 0.1 相当于原值差 6553.5，远大于这批数据的常见邻域差值。

此处的深度监督接近“所有有效邻域均连续”，32 张两个尺度都没有小于 0.5 的深度边目标。它允许近常数正预测取得很小误差，削弱增加独立边监督的目的。这是新增目标在真实观测范围上的退化风险，不能归因到已完成的 relation_v1 实验，也不代表发现了真实深度数据本身没有结构。

### 热图是伪彩色外观，不是温度标量

这 32 张 thermal 文件均为 RGB，逐像素 RGB 通道最大差都达到 255，并非复制成三通道的灰度图。已视觉检查 `Train/T/1.png`，是彩虹伪彩色热图。`convert("L")` 得到的是调色板亮度投影，不能称为温度或原始热响应；它还可能把不同伪彩色映射成相近亮度。保留完整 RGB 并定义热图颜色外观连续性更符合当前可取得的数据，不应宣称恢复了物理温度。

针对这两项发现，正在修正的设计拟保留热图 RGB，使用每图有效观测的 q05–q95 对比度范围定义相对差异：深度为相对深度观测差，thermal 为伪彩色 RGB 的颜色 RMS 差。固定 tau=0.1 作用于归一化后的相对变化，而非 16 位存储满量程。常数观测与无效观测必须显式处理，不能为得到非均匀分布而人为制造边。这些定义改变应版本化 `structure_target_spec` 与预处理元数据，以防误用旧 artifact。

### 修正后：同 32 个训练图像的目标分布

已按完全相同的 32 个 ID 复核落盘后的 `typed_observation_edges_v2`。新 loader 的 thermal 输入为 3 通道、depth 为 1 通道；有效性 mask 为单通道。相对范围通过每图每通道有效像素的 q05–q95 计算，再跨通道求 RMS；确定性采样每通道最多 4096 个有效点。分位范围为零时回退至完整有效范围，常数图像再回退至 1，因此不会为常数观测人为添加变化。

有效边比例的分母是该网格所有不含自身、且不越界的边数，再跨图平均；padding 没有算作传感器无效。其余统计仍对全部有效边汇总。32 张图像各类型各尺度都保留有效边，没有全无效样本。

深度不再接近全 1：两个尺度的低连续性目标比例从 0 变为约 15.44% / 24.06%，标准差从约 0.0064 / 0.0050 增至 0.2277 / 0.2723。该变化并非少数异常图像独自造成：深度逐图 target 标准差最小值为 0.089973 / 0.081479，逐图 target<0.5 比例最小值仍为 0.009400 / 0.002793，32 张图都同时具有不同强度的边。更粗网格相邻位置的物理间距更大，平均连续性降低，与这一定义相容。

这项复核支持“观测目标具有实际区分度，修复了存储满量程造成的常数退化”，不等于验证了真实对象边界。纹理、伪彩色调色板、传感器噪声、深度内部起伏都可能产生低连续性边；目标只表达相对观测差异，应由 COD 语义分支和任务读出决定何时采用。没有恢复物理温度、没有生成伪模态，也没有据此得到 COD 性能提升结论。
